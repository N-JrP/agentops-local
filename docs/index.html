What happens in the full local runtime?

The evidence is passed through LangGraph to Ollama for synthesis, then checked for grounding and completeness before persistence. The repository contains the complete runtime.

SYSTEM ARCHITECTURE

Explicit orchestration, not one opaque model call.

Planning, evidence collection, synthesis, validation, persistence and observability are separate concerns, making the workflow testable and inspectable.
