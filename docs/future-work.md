# Future work

These are optional extensions, not missing requirements for the current architecture:

- Add another public Statuspage-compatible provider to demonstrate multi-source federation.
- Add authenticated enterprise connectors when a real organization can provide access.
- Add a write-capable remediation tool only with explicit approval and audit policy.
- Add pgvector only if semantic runbook retrieval grows beyond the current small deterministic corpus.
- Add Redis only if measured latency or concurrency demonstrates a real cache/state need.
